# Multilingual Embedding Benchmark

AIMultiple evaluation of ten embedding models on approximately 606,000 Amazon reviews in six languages. The published comparison measures retrieval accuracy and query latency when questions search reviews in the same language.

> [Read the benchmark on AIMultiple](https://aimultiple.com/multilingual-embedding-models)

## Retrieval task

- German, English, Spanish, French, Japanese and Chinese reviews are indexed in Qdrant.
- Queries reference specific details from a source review.
- A hit requires an exact product identifier match within the first 1, 3, 5 or 10 results.
- Latency includes query embedding and vector search on an H100.

## Retrieval accuracy

Multilingual E5 Base records 16.5% Top-1 accuracy averaged across the six languages. E5 Small follows at 12.7%, while Llama Embed Nemotron 8B reaches 12.0%.

The strict matching rule gives no credit to a similar review with a different product identifier. These scores describe that retrieval task. The questions are generated by an LLM, and the language corpora differ in size.

The linked article provides the model roster, per-language results and evaluation procedure.
